# Machine Learning II Lab

A set of Jupyter notebooks demonstrating machine learning and data mining algorithms.

## Overview

This repository collects lab exercises across exploratory data analysis, supervised learning, clustering, rule learning, Bayesian networks, and ensemble methods.

## Included Topics

- Exploratory data analysis
- Candidate Elimination and Find-S
- Sequential covering and FOIL
- k-Means clustering and Self-Organizing Maps
- Bayesian networks
- Bagging, boosting, and SHAP

## Tech Stack

Python, Jupyter Notebook, pandas, NumPy, Matplotlib, and scikit-learn (used by the notebooks).

## Installation and Execution

Install Jupyter and common notebook libraries:

```bash
python -m pip install jupyter pandas numpy matplotlib scikit-learn
jupyter notebook
```

Open a notebook and run its cells in order. Some exercises may require additional libraries or data specified within that notebook.
