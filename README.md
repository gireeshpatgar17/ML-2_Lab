# Machine Learning II Lab

A collection of standalone notebooks for machine learning and data mining exercises.

## Notebook Index

| Notebook | Topic |
|---|---|
| `EDA_Lab1.ipynb` | Exploratory data analysis |
| `Find_S_Algorithm_Lab2.ipynb` | Find-S concept learning |
| `Candidate_Elimination.ipynb` | Candidate Elimination |
| `Sequential_Covering.ipynb` | Sequential covering |
| `FOIL_Algorithm.ipynb` | FOIL rule learning |
| `K_Means_Clustering.ipynb` | k-Means clustering |
| `Self_Organizing_Maps.ipynb` | Self-Organizing Maps |
| `Bayesian_Network.ipynb` | Bayesian networks |
| `BaggingBoosting.ipynb` | Bagging and boosting |
| `Bagging_and_SHAP.ipynb` | Ensemble learning and SHAP |
| `Program_2.ipynb` | Iris classification with a decision tree |

The notebooks are independent lab exercises rather than stages in a shared pipeline.

## Tech Stack

Python and Jupyter Notebook. Individual notebooks use libraries such as pandas, NumPy, Matplotlib, Seaborn, and scikit-learn.

## Run a Notebook

Install Jupyter and common dependencies, then open the notebook you want to run:

```bash
python -m pip install jupyter pandas numpy matplotlib seaborn scikit-learn
jupyter notebook
```

Run its cells in order. If a notebook imports an additional package, install that package in the same Python environment before running it.
